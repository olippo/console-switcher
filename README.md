# Console Switcher

**App Switcher & Control Center overlay** for Android gaming handhelds, powered by **Shizuku**.

## Requirements & Setup

The app requires [Shizuku](https://shizuku.rikka.app/) to query running tasks and live app thumbnails, switch between or force-close background apps, toggle protected system settings, and control handheld hardware modes (performance, fan speed, etc.).

The App Switcher and Android toggles work on any Android device with Shizuku; device specific hardware controls are supported on Retroid Pocket & AYN Odin handhelds.

## Usage

I suggest binding Console Switcher to a dedicated handheld button using [Key Mapper](https://github.com/keymapperorg/KeyMapper).

## Building

```bash
./gradlew assembleDebug
```
